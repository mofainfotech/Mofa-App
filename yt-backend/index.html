Backend Endpoints & Features

Explore Endpoints ▼

This backend provides core PHP REST endpoints with zero external dependencies, powered by yt-dlp & FFmpeg.

GET /api/formats?url={youtube_url}

Extracts video metadata (title, thumbnail, duration) and lists available resolutions (4K, 1440p, 1080p, 720p, etc.) with pre-configured download URLs.

GET /api/download?url={youtube_url}&format_id={format_id}

Downloads media. For merged video+audio formats, executes FFmpeg to combine video with best audio, saves into downloads/, and triggers direct download.

GET /api/status

Returns health status, yt-dlp version, PHP version, and FFmpeg availability.

GET /downloads/{filename}

Streams processed files with Content-Disposition: attachment for immediate browser file saving.
